# Web Smoke Test
## 기본 경로
- [ ] 로그인/로그아웃
- [ ] 권한별 메인 화면 진입
- [ ] 메시지 발송 화면 진입 및 Validation
- [ ] 주요 조회/검색
- [ ] 관리자 핵심 기능
- [ ] 외부 연계가 포함된 대표 경로
## 판정
HTTP 오류, JS 오류, 핵심 API 실패, 권한 오동작이 있으면 Pass 처리하지 않는다.
## Evidence
실행시각, 환경, 버전, 결과, 오류 근거를 기록한다.
